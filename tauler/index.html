Inclou les sessions de Claude Code fetes en aquest PC (també els agents auxiliars). Les sessions anteriors fetes a claude.ai/code (web) no són al PC i no hi compten. «Llegits de memòria cau» són tokens de context reaprofitat, molt més barats que els generats.

Sobre el cost. És el que costarien aquests tokens a preu de l'API d'Anthropic, en dòlars (Preus públics de l'API d'Anthropic (consultats el 21/11/2026); Opus 5.5: 4 $ entrada, 20 $ generats, 0,20 $ de memòria cau per milió de tokens). Si fas servir Claude Code amb una subscripció, no és el que pagues: serveix per veure quant ha costat cada part. Els preus es poden canviar a tauler/config.json.

Es regenera sol en acabar cada torn de Claude Code en aquest projecte, o a mà amb npm run tauler.
